# App

A Next.js full-stack app (App Router, TypeScript) on Prisma + PostgreSQL, with shadcn/ui on
Tailwind CSS and vitest. Generated by Delivery OS from the `crud-saas` starter.

## Run locally

```bash
cp .env.example .env            # set DATABASE_URL
pnpm install
export $(grep -v '^#' .env | xargs)
pnpm db:migrate && pnpm db:seed  # demo admin: admin@example.com / demo-password (dev only)
pnpm dev                         # http://localhost:3000
```

## Checks

```bash
pnpm lint        # Biome
pnpm typecheck   # Prisma client + Next route types + tsc
pnpm test        # vitest; needs DATABASE_URL pointing at a database named *_test
pnpm build
```

## Deploy

`docker build .` produces the production image (`next start` on port 3000, healthcheck on
`/api/health`). Run migrations and the seed as one-shot containers from the same image:
`node_modules/.bin/prisma migrate deploy`, then `node_modules/.bin/tsx prisma/seed.ts` with
`SEED_ADMIN_PASSWORD` set.
